# CHG-0074

- 树：连接线进一步弱化；选中为 1px 青色描边、6px 圆角；操作图标从行中间右侧弹出，默认隐藏，仅 hover 可见，透明底；
- 主数据页：节点路径点击复制；Data 元信息按内容/版本分表；Stat 按版本与事务、时间、结构分组，两列展示；
- 创建对话框：Mode 改为深色单选框组，选中高亮；
- Esc：工作区关闭弹窗/菜单，无弹窗时返回首页；审计、可观测、设置页 Esc 返回上一页；
- 右侧栏：节点信息 / 最近节点与操作历史 Tab / 变更记录三段；左右分隔条可拖动，宽度保存到 localStorage；
- 命令区：错误提示移到输入框下方；输出字号与行距调整；
- 路径跳转输入框支持 Tab 路径补全；
- 设置页：除代理外变更自动保存并显示「已保存」；代理仍需显式保存。
