# CHG-0018：主工作台 UI 架构与交互决议

## 目的

确定首版主工作台的信息架构、数据区模型与命令区形态，作为实现与线框图迭代的基础。

## 决策

1. 组件库：Naive UI；编辑器 CodeMirror 6（`DEC-003`）。
2. 布局：顶栏 + 左侧连接与树 + 中间多标签数据区 + 右侧可折叠检查器（Stat/ACL）+ 底部默认折叠的命令区与结果面板 + 状态栏，共七个区域。
3. 多标签：同一连接同一路径去重；脏标签关闭时提示； **切换连接不关闭标签**，每个连接的标签集合独立保留， **默认仅保留最近 3
   个连接**，被移除连接的标签含未保存内容时必须先提示。
4. 命令区：默认折叠、可拖拽展开并记忆高度；结果与历史以标签并列；写操作确认条插在结果区上方。
5. 检查器：右栏上下两段，Stat 与 ACL 只读；ACL 编辑只走命令行 `setAcl`。
6. 状态呈现：树五态、数据区两视图与保存态、连接六态、数据新鲜度横幅。
7. 快捷键：执行当前行、执行全部、补全、刷新子树、清空结果、保存标签、关闭标签、切换标签。
8. 窗口最小建议尺寸 1024×640。

## 影响

- `02-design/ui-design.md` 重写为布局、标签模型、状态、流程、快捷键与组件映射。
- 新增语句 `REQ-UI-TABS-001`（标签保留与未保存提示）与用例 `VER-UI-TABS-001`。
- 未改变既有布局语句（六区域）与检查器只读约束。

## 非目标（Non-Goals）

1. 不定稿视觉令牌（颜色、字号、间距、图标）。
2. 不设计窄屏与移动端。
3. 不提供 ACL 编辑界面。
4. 不设计巡检与时间线面板。
5. 不决定系统原生菜单形态。

## 候选方案与权衡（Alternatives & Trade-offs）

**数据区单标签**：实现简单但无法并行查看与对比，切换丢失上下文；被拒绝。

**检查器并入数据标签**：节省右栏空间，但元信息与编辑区争抢高度，且每个标签重复渲染；被拒绝。

**命令区常驻**：随时可用，但挤压主工作区，与使用分布不符；被拒绝。

## 遗留

- 系统原生菜单与应用内菜单如何取舍。
- macOS 上 `Cmd+W` 的语义冲突。
- 标签数量与内存的实测关系（`REQ-UI-PERF-001`）。
