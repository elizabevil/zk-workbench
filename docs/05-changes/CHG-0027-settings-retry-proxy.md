# CHG-0027：设置页、重试策略、代理档案与审计保留期确认

## 决策

| 项 | 决定 |
|---|---|
| 重试 | 默认开启，最多 5 次，间隔 3s 递增至上限 10s，可在设置中修改 |
| 代理档案 | 允许多条，按配置顺序依次尝试，全部失败才报错 |
| no_proxy | 首版提供，支持精确主机与域名后缀 |
| 审计保留期 | 默认 90 天，可配置，清理二次确认 |
| OTel | http/protobuf，端点与采样率可配置，默认关闭 |
| 设置页 | 独立页面，含语言、主题、通知、重试、任务行为、代理、可观测、审计、日志，并提供恢复默认 |

## 语句变更

新增：`REQ-CONN-PROXY-004`、`REQ-CONN-PROXY-005`、`REQ-CONN-RETRY-001`、`REQ-UI-SETTINGS-001`、`REQ-OPS-AUDIT-006`；各配一条 `pending` 用例。

## 配置模型

`config/app.toml` 增加 `[notifications]`、`[retry]`、`[task]`、`[proxy]`（含有序 `[[proxy.profiles]]` 与 `no_proxy`）、`[observability.otel]`、`[audit]`。密码仍只进 keyring，不写入配置文件。

## 考虑点

1. 有序代理回退需要记录每条档案的失败原因，最终错误聚合展示。
2. `no_proxy` 匹配规则与浏览器/系统语义保持一致，先支持精确主机与后缀。
3. 重试间隔 3s→10s 与倍率 2 的组合为 3、6、10、10、10（封顶），需在 UI 说明。
4. 恢复默认设置不得清除凭据与审计记录，只重置配置项；清理审计是独立操作。
5. 设置变更即时生效的范围：语言/主题/通知立即生效；代理与重试对新建连接生效，已有连接提示重连。

## 非目标（Non-Goals）

1. 不允许关闭删除确认、CAS 与脚本首错停止。
2. 不在恢复默认时删除审计或凭据。
3. 不实现 SSH Tunnel（第二阶段）。
4. 不默认外发遥测。
5. 不提供代理测速或自动选择最快代理。

## 候选方案与权衡（Alternatives & Trade-offs）

**单一代理**：无法覆盖公司代理 + 本地代理并存；改为有序多档案。

**重试无限次**：故障时会产生持续重连风暴；改为 5 次封顶并可配置。

**审计清理不确认**：可能误删追溯数据；改为二次确认并展示范围。

## 验证

`just --justfile docs/justfile check` 应输出 `RESULT: PASS`。
