# CHG-0004：首版交互与需求待决项集中审批

## 目的

合并当前 PRD、设计和脚本讨论中的未决项，按对首版体验的影响排序，集中确认一组默认方案。用户未确认的推荐不自动成为产品基线。

## 已确认的产品方向

- 产品聚焦 ZooKeeper；借鉴同类产品交互，不扩展为多中间件。
- 第一阶段是单节点可靠操作工作台；第二阶段是节点数据维护与迁移；第三阶段是集群巡检。
- CLI 只操作 ZooKeeper，不是系统 shell；支持补全、保存命令/脚本。
- 脚本按顺序执行，支持单行和全部执行；换行与 `;` 结束命令；首条失败立即停止；查询结果逐条保存并折叠查看。
- UI 交互采用 DataGrip 式多连接工作台作为参考。

## 集中审批项

可按 A-F 批量回复“通过/修改”。推荐默认值供快速收敛。

### A. 首版单节点闭环（现在需定）

**推荐**：连接一个 ZooKeeper 集群工作区后，用户可以路径直达一个 znode，查看数据、Stat、ACL，修改数据并用 version CAS
保存；失败显示明确原因；用户可刷新，并在重连后看到数据可能过期提示。ACL 写入、递归删除、批量编辑不列为首版必要能力。

**理由**：满足“可靠节点操作”核心，同时隔离高风险扩展；是否包含 ACL 写操作是影响范围和安全性的关键选择。

请确认首版 ACL：只查看 / 查看与编辑（推荐后置 ACL 编辑）/ 其他。

### B. 首版连接数（现在需定）

**推荐**：可以保存多个连接配置，但首版同时只激活一个工作区连接；多连接并列、后台保持会话放后续阶段。工作区配置中显示当前目标连接。

**理由**：“单节点”不等于单集群，但首版核心闭环不需要多个同时活跃 session；保存连接档案保留基本连续性。

请确认：保存多个配置、首版单活动连接 / 首版支持同时打开多个连接 / 其他。

### C. 数据查看与编辑（现在需定）

**推荐**：原始字节/文本是基准视图；首版支持纯文本与 JSON 格式化/校验，YAML 高亮和格式化可进入第二阶段；自动识别只提示，不自动转换。保存前显示
diff 并使用读取时 version 做 CAS。无法解码的数据提供只读十六进制视图。

**理由**：避免格式化悄悄改变 ZooKeeper 中的字节；先覆盖最常见且相对明确的格式。

请确认首版格式：文本+JSON（推荐）/文本+JSON+YAML/其他。

### D. 认证身份（需定边界，可分阶段交付）

**推荐**：连接级认证配置进入首版；路径前缀到认证配置的本地绑定先作为第二阶段能力。每个身份配置对应独立 ZooKeeper
client/session；首版可由用户显式切换连接身份，不在单一 session 上静默叠加账号。任何失败都显示当前身份标签和权限错误，不静默轮试其他凭据。

**理由**：ZooKeeper 认证与客户端连接关联；按路径绑定属于本地产品策略，会引入路径解析、连接选择和状态提示复杂度。

请确认：连接级认证首版，路径绑定后置（推荐）/路径绑定必须进入首版。

### E. CLI 与脚本编辑（首版/第二阶段边界）

**推荐**：首版提供命令输入、自动补全、基础高亮、单行执行及可保存 UTF-8
文本脚本；默认应用脚本目录，支持打开文件，不做通用文件管理器。脚本首版只支持顺序命令、空行和注释，不支持变量、条件、循环或任意
JS。执行前显示连接和写操作摘要；结果按命令行折叠。复杂目录管理和高级编辑功能后置。

**理由**：直接满足测试流程需求，同时避免把应用 CLI 扩成通用 IDE/脚本运行时。

请确认：按此首版范围 / 把脚本编辑器整体后置 / 需要增加某项能力。

### F. 工作台布局与状态反馈（可先作为设计基线）

**推荐**：左侧连接/节点树，中间标签式数据工作区，右侧可折叠 Stat/ACL 检查器，底部可折叠
CLI/脚本与输出区。所有操作显示当前连接身份；树、数据、命令、脚本分别定义加载中、空、失败、过期、未保存、冲突等状态。允许调整面板宽度并记住布局。

**理由**：映射 DataGrip 多工具窗模式，令 CLI 和节点编辑可同时工作；具体视觉样式后续用线框图迭代。

请确认是否采用该信息架构作为 UI 初稿。

## 可后置但需要进入验证计划

以下问题当前不阻塞交互方向，先安排验证或后续设计：

1. 缓存 TTL/容量和活动连接资源上限：通过大树、高延迟及多连接测试决定，不预设固定数字。
2. Rust 客户端并发、认证、ACL、version CAS、Watcher 与断线恢复能力：必须用目标版本实测。
3. 文件脚本语法中的引号/转义/字符串内分号规则：实现 parser 前在 CLI 规格确定。
4. 全树搜索、批量导入导出、审计保留周期、四字命令阈值：按第二/第三阶段另行审批。
5. 操作系统最低版本、签名/自动更新和凭据钥匙串：在首版发布范围确认前收敛。

## 负责人审批结果

- A：首版支持常见 CRUD；ACL 权限管理后置。
- B：同意推荐方案（可保存多个连接配置，首版单活动连接）。
- C：JSON/YAML 查看时格式化；两者支持高亮；提供基本搜索与替换。查看格式化不修改 ZooKeeper 存储内容。
- D：路径级认证身份绑定作为第二版交付。首版连接级认证配置仍作为访问集群的基础能力。
- E：同意推荐方案（顺序/单行脚本、基础编辑器、无通用 shell/脚本语言）。
- F：同意推荐工作台信息架构。

产品和交互决议已同步到 PRD、路线图、功能规格和 UI 设计说明。

本审批包已完成。剩余未定实现细节按 `04-test/validation-roadmap.md` 的阶段准备验证；需求讨论阶段不把计划写成验证结果。

## 后续仍需确认的事项

以下事项不推翻本审批包，按讨论阶段安排：

### 首版行为边界（实现前需要讨论）

1. **删除模式与影响预览**：已确认支持递归且删除必须确认；仍需确定首版提供哪些删除模式、能否预览完整路径/数量，以及部分失败如何报告。→
   已由 `CHG-0006` 收敛为 D1 方案。
2. **节点创建选项**：已确认支持所有节点类型；仍需确认是否允许一次创建缺失的父路径，以及临时/顺序节点的创建交互。→ 已由
   `CHG-0006` 收敛为 C1 方案。
3. **ACL 查看**：ACL 编辑已后置；首版是否只读显示 ACL，或完全不提供 ACL 面板？推荐首版只读显示，帮助用户解释权限错误。→ 已由
   `CHG-0009` 收敛为首版只读显示。
4. **原始字节**：不可解码数据采用只读十六进制预览并禁止编辑，还是允许用户用文件/十六进制输入完整替换？推荐只读预览 +
   显式完整替换流程，不做逐字节内联编辑；替换前展示字节差异并使用 version CAS。
5. **脚本编辑器最小范围**：应用默认脚本目录、打开/保存普通文件、行号和基础编辑器能力；脚本中的注释、空行、引号/转义及字符串中的
   `;` 解析规则。
6. **查询结果保留**：已确认限于当前运行或当前 session；仍需定义切换连接/身份时如何清除或隔离。
7. **首版成功标准**：核心任务如何验收，例如目标节点定位与读写完成、冲突不丢数据、重连后不展示陈旧状态；具体可测指标待场景确定。

### 可进入验证阶段再定的参数

1. 树缓存 TTL、容量和失效策略。
2. 最大活动连接数和后台连接保活策略。
3. 最大节点数据尺寸、预览阈值、编辑器性能和搜索替换性能。
4. Rust 客户端并发、认证、version CAS、Watcher 和重连保证。
5. 三平台最低系统/WebView 版本、凭据钥匙串和打包/更新细节。
6. 巡检阈值、轮询间隔与负载——属于第三阶段。

这些验证项见 `04-test/validation-roadmap.md`；在目标版本、平台和测试判据明确前，不把数值写成产品承诺。
