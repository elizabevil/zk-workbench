# CHG-0006：首版删除模式与节点创建行为决议

## 目的与范围

收敛 `CHG-0004`「后续仍需确认的事项」中的两项行为边界： **删除模式与影响预览**、 **节点创建选项**。本记录只覆盖首版（阶段
1）删除与创建两个动作，不改变 PRD 的产品范围，也不涉及 ACL 编辑、导入导出、巡检等后置能力。

## 决策来源与状态

产品负责人已确认以下两项推荐方案，状态为 **已确认基线**：

- 删除：采用「单一入口 + 显式勾选递归 + 影响预览 + 分项报告」（下称 D1）。
- 创建：采用「不静默创建缺失父路径 + 显式创建选项 + 服务端路径回显」（下称 C1）。

行为细节写入 `03-specs/tree-query-connections.md`，界面状态写入 `02-design/ui-design.md`，验证场景写入
`04-test/test-plan.md`。本记录不替代规格正文。

## D1：删除模式与影响预览

1. **单一入口，禁止隐式升级。** 界面只提供一个删除入口；空节点的确认对话框只能执行「删除该节点」，非空节点的普通删除按钮置灰不可用。
2. **显式递归。** 非空节点必须由用户勾选「同时删除全部 N 个后代」后，确认按钮才可用；勾选前后都不得把普通删除静默升级为递归删除。
3. **影响预览。** 勾选后惰性遍历子树，展示前 100 条路径与后代总数；总数超过 5000 时只显示 `≥5000`。遍历可取消、不阻塞界面，执行时以服务端实际树为准。
4. **分项结果。** 执行结果必须区分「已完成 X / 失败于 <path>（错误类别）/ 未执行 Y」，可展开逐条；提供「仅重试失败子树」，禁止自动重试。
5. **不做「删除父节点下指定子节点」的批量选择模式**，删除范围始终是选中节点及其全部后代。

## C1：节点创建行为

1. **不静默创建缺失父路径。** 父路径不存在时创建失败并明确报错；对话框提供显式勾选项「创建缺失的父路径」，勾选后才创建，且中间节点固定为持久节点，界面注明该限制。
2. **创建对话框字段固定为**：路径、节点类型（持久 / 临时 / 顺序 / 临时顺序）、数据（按原始文本提交，不做自动格式转换）、是否创建缺失父路径。
3. **顺序节点。** 输入值作为路径前缀，创建成功后定位到服务端返回的完整路径并高亮，结果区显示实际路径。
4. **临时节点。** 确认区提示「随会话结束删除；断线重连后该节点可能已不存在」，会话 generation 变化后刷新父节点列表。

## 非目标（Non-Goals）

1. 不改变 PRD-003 已确认的产品范围（递归操作仍属首版能力）。
2. 不实现「删除父节点下指定子节点」的批量选择模式。
3. 不提供批量多节点删除队列、后台任务或跨连接批量操作。
4. 不定义 ACL 编辑、导入导出、巡检等后置能力的行为。
5. 不在本记录中确定预览遍历的上限实现方式（串行 / 并发、超时阈值），该参数由阶段 1 实测决定。

## 候选方案与权衡（Alternatives & Trade-offs）

### 删除：显式命令式三入口（D2，已拒绝）

提供「删自身 / 删子树 / 删指定子节点」三个并列入口。拒绝原因：第三个入口的确认界面难以表达影响范围，且与「一次围绕一个目标
znode」的首版定位冲突；并列入口增加误选风险，收益不足以抵消。

### 创建：默认递归创建缺失父链（C2，已拒绝）

父路径缺失时自动创建整条链。拒绝原因：一次误操作可能产生大量持久节点，中间节点类型不可选，违背「写操作显式、可预览」原则；错误信息也不足以让用户判断实际影响。

### 预览：执行前完整枚举整棵子树（已拒绝）

预览时遍历全部后代并缓存完整列表。拒绝原因：大子树会产生大量请求与内存占用，且预览与执行之间树仍可能变化，完整枚举带来的确定性收益有限；改为有上限的预览并声明非原子性。
