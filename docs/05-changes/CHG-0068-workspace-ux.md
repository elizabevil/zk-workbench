# CHG-0068

- 路径规范化：`/a`、`/a/`、`//a` 统一为 `/a`；跳转、标签、选择、创建均使用规范化路径；跳转占位符改为可理解提示；
- 树高亮当前节点，双击节点直接打开编辑器；
- 数据格式改为分段按钮（原始/JSON/YAML），不再使用难读的原生下拉；
- 顶栏审计/可观测/设置收敛到“工具”菜单；
- 命令历史默认折叠，避免与输出混在一起；
- 新增可配置快捷键（localStorage）：编辑、新建、删除、刷新、聚焦跳转；设置页提供录制与恢复默认。

## 验证

```text
just check  exit 0
vue-tsc / biome 通过
```
