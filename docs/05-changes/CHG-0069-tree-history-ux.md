# CHG-0069

- 创建/编辑等通知改为右上角浮层，3.5 秒自动消失，不占布局；
- 命令执行失败时输出区直接显示错误文案与 detail，不再显示空占位；
- 树展开状态按连接持久化到 localStorage；新增展开全部（上限 2000 节点）/收起全部；节点 hover 显示新建子节点/删除图标；
- 命令历史从命令面板移到右侧检查器底部“操作历史”，纵向列表点击重跑；时间线同样可折叠；
- 设置页左侧导航点击立即高亮并滚动到对应分区，滚动同步在点击后短暂抑制，避免跳回。

## 验证

```text
just check  exit 0
vue-tsc/biome 通过
```
