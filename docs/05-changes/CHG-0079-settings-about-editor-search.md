# CHG-0079

- 命令错误不再在输入框下方追加一行，直接显示在输出区，避免被状态栏裁切；
- 数据区元信息保持紧跟数据内容，分隔线改为虚线；
- 右侧检查器与变更记录增加折叠箭头；
- 设置页左栏导航文字水平/垂直居中，右栏改为标签在左、控件在右的单行布局，复选框靠右；
- 设置页 header 改为整窗宽度，返回按钮贴右上角，并显示当前缩放百分比；
- 移除设置页每个 fieldset 的 `backdrop-filter`，保留半透明背景，减少模糊层；
- 关于弹框改为应用内布局：图标、应用名、版本、TECH STACK、Website/GitHub/Release Notes/Support 占位、开发者与版权；
- 编辑弹框移除独立预览视图，改为编辑器内行级 diff 提示；
- 编辑弹框搜索/替换默认隐藏，`Ctrl/Cmd+F` 打开搜索、`Ctrl/Cmd+R` 打开替换；搜索条单行显示 `Cc`、`W`、`.*`、结果计数与上下箭头。
