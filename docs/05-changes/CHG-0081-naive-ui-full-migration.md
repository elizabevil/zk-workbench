# CHG-0081

- 首页：`NButton`、`NInput`、`NEmpty`、`NAlert`；
- 连接弹框、节点创建/删除/二进制替换、关于弹框迁移到 `NModal`；
- 命令区输入与执行按钮迁移到 `NInput` / `NButton`；
- 工作区树头、数据工具栏、格式切换迁移到 `NButton`；
- 审计页迁移到 `NDataTable` + `NButton` / `NInput` / `NInputNumber`；
- 可观测页迁移到 `NCard` / `NGrid` / `NStatistic` / `NCheckbox` / `NInput` / `NInputNumber` / `NButton`；
- 树、工作区分栏、数据标签、NodeEditor 的内联 diff 与搜索保留原生实现；
- `NModal` 的 `close-on-esc` 关闭，统一由页面/组件自行处理 Escape，避免与工作区快捷键重复关闭。

## 后续修复

- 树刷新按钮只重建树；数据刷新按钮只重新获取当前节点数据；快捷键和命令写操作才同时刷新。
- 数据刷新支持关闭、1 秒、5 秒、10 秒和自定义间隔的自动刷新。
- 外观增加字体颜色、字体透明度与工作区字号，预览同时展示两套字号。
- 数据刷新按钮释放焦点，字节/编码/版本/时间移至页面底部状态栏。
- `ls`、`get` 等只读命令不再刷新树和数据，只更新命令输出。
- 右侧检查器增加左右内边距，Stat、最近节点、操作历史长值可换行完整展示，列表字号调整为 11px。
- 命令框 Tab 在候选列表中循环，并显示带当前选中项的候选提示。
- 工作区 toast、设置页代理测试/保存提示自动消失。
- 关于弹框移到 App 根部，避免打开时重渲染工作区树；关于链接改为可配置 URL，通过原生命令打开外部浏览器。
- 设置页标签左对齐、按钮右对齐、滚动导航高亮，左栏顶部与右侧内容对齐。
- 设置页增加重置缩放按钮和 Ctrl+0，重置到 100% 且保留界面字号设置。
- 编辑连接卡片调整间距和端口宽度。
