# CHG-0059：工作区多标签、检查器与时间线

## 交付

| 项 | 内容 |
|---|---|
| 数据标签 | 每个连接独立标签集合；点击节点打开/复用标签；可关闭；默认只保留最近 3 个连接的标签 |
| 过期响应 | 节点读取使用请求序号，旧响应不会覆盖新选择 |
| 树状态 | 未加载/加载中/空/错误四种可视状态，错误可重试（“可能过期”由 generation 重挂覆盖） |
| 检查器 | 右侧面板显示路径、版本、子节点数、数据长度、临时节点与修改时间 |
| 时间线 | 检查器下方显示该路径最近 10 条审计记录 |
| 命令区 | 底部命令面板（上一提交）构成第六区域 |

## 未完成

- 标签内容仅按路径保存，编辑器草稿未按标签隔离；
- 移除连接时若有未保存内容，尚未弹窗提示（`REQ-UI-TABS-001` 的未保存部分）；
- 面板宽度不可拖动调整，布局未持久化（`REQ-UI-LAYOUT-001` 部分）。
