# CHG-0072

- 节点前使用 `├─` / `└─` 连接线与 `│` 祖先参考线，层级关系与 `tree` 命令一致；
- 折叠/展开仍用 `▸` / `▾`；
- 删除围绕节点漂浮的常驻按钮，改为行尾内联操作：`+` 新建子节点、`✎` 编辑、`×` 删除；
- 操作按钮仅在鼠标悬停该行时出现，选中行不常驻显示；
- 整行选中、双击编辑、Delete 删除保持不变。

## 验证

```text
just check  exit 0
vue-tsc/biome 通过
```
