# CHG-0034：产品化壳层

## 变更

| 区域 | 之前 | 之后 |
|---|---|---|
| 启动页 | 直接显示连接表单（连通性测试形态） | 连接主页：已有连接卡片、空状态、新建入口 |
| 连接后 | 停留在原页，只显示状态 | 跳转 `/workspace` 工作区 |
| 工作区 | 无 | 顶栏左上角连接选择器（名称、地址、状态）、节点树占位、内容区占位、底部状态栏 |
| 连接切换 | 不支持 | 支持多活动连接切换、断开、返回主页 |

## 路由

```text
/           连接主页
/workspace  工作区（无活动连接时重定向回主页）
/settings   设置
```

## 接口

- `ConnectionSnapshot` 增加 `host`、`port`；
- 新增 `connection_list` 命令，返回活动连接快照；
- 前端事件监听从工作区上移到 `App.vue`，主页与工作区共享状态。
