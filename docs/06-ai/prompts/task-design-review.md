# 设计评审任务提示词

```text
任务：评审 ZK UI 某项技术或交互设计。

目标：确认设计满足已确认需求与约束，明确取舍、依赖、失败模式和验证方式。

工作方式：
1. 读取相关 PRD、现有设计、功能规格、测试计划和引用证据。
2. 区分来源事实、项目推论、假设与待验证能力。
3. 检查错误/断连/重试/并发/权限/资源生命周期及跨连接隔离（只在相关时）。
4. 提出最小可行设计和替代方案；标出可快速审批与必须负责人决定的事项。
5. 不把建议写为既定决策；确认后再更新设计或 ADR/CHG，并同步测试计划。

验收：设计能追溯到需求，风险有对应验证或处置，未确认决策仍清楚可见。
```
