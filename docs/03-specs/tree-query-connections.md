# 树浏览、快速查询与多连接规格

## 范围

定义节点树加载、缓存、快速定位、已加载节点搜索及多连接状态隔离。全树数据内容搜索不在本规格内。

### SPEC-TREE-001 按需展开

展开路径时才读取其直接子节点；普通树浏览不得递归加载未展开的分支。

### SPEC-TREE-002 复用与刷新

同一连接、同一路径在缓存有效期内重复展开可复用结果。用户可刷新当前节点；重连、generation 变化或收到相关子节点事件时使相应条目过期。

### SPEC-TREE-003 路径直达

用户输入绝对路径后，应用直接查询路径是否存在并读取目标节点，不要求先在树上逐级点击展开。

### SPEC-TREE-004 本地范围搜索

名称或路径搜索仅覆盖当前连接已经加载的路径索引。界面必须说明搜索范围，不能把局部命中或无结果表述为全局结果。

### SPEC-CONN-001 连接隔离

每个逻辑连接有独立 session、状态、generation、Watcher、缓存命名空间和审计上下文。一个连接的重连或失效不得污染另一个连接。

### SPEC-CONN-002 同连接复用

同一逻辑连接下的面板和操作复用该连接的长期客户端；不得每次操作新建 ZooKeeper session。

### SPEC-CONN-003 生命周期

连接状态至少区分创建中、连接中、已连接、断开/重连中、会话过期和关闭。关闭连接时清理其 Watcher、任务和客户端资源；应用退出时有序关闭全部连接。

## 待补充的验收细节

## 首版基础节点操作

- 首版支持所有 ZooKeeper 节点类型，包括持久、临时、顺序及其合法组合；创建流程说明所选类型会产生的行为，例如临时节点的生命周期和顺序节点的服务端路径后缀。
- 首版支持创建、读取、修改、删除及递归操作。
- ACL 权限管理后置，不属于首版交付。
- 删除始终视为危险操作，任何删除都必须由用户明确确认。确认界面展示操作类型、目标路径和影响范围。
- 删除配置按使用场景区分：仅删除选中节点（节点为空时可成功）、删除选中节点及全部后代、从选中父节点删除指定子节点等。对中间节点/非空节点必须明确显示将影响的子树；不得将普通删除隐式升级为递归删除。
- 批量/递归操作在确认前尽可能预览受影响路径或数量；执行中显示进度，失败时报告已完成与失败部分。若服务端无法原子完成，不得把部分失败呈现为整体成功。
- 创建临时节点时提示其会话生命周期；顺序节点显示服务端最终生成的完整路径。

## JSON/YAML 查看与编辑

- JSON 和 YAML 均支持语法高亮；查看模式可格式化和折叠/展开内容。
- 查看模式格式化只改变展示，不改变 ZooKeeper 返回的原始字节，也不触发写入。
- 编辑器支持基本搜索与替换；替换只修改本地草稿，只有用户明确保存才提交。
- 编辑模式明确显示未保存状态；保存前显示 diff 并用读取时 version 做 CAS。
- 格式校验失败时显示错误位置，不丢弃或覆盖原始内容。
- 搜索/替换参考成熟数据库/代码编辑器：支持当前文档内查找、上/下一个、匹配计数、替换当前项、替换全部；大小写、整词和正则选项由编辑器规格确认。替换全部前提供匹配数与撤销能力。

## 不可解码的原始字节（待定策略）

ZooKeeper 节点数据是字节内容。若数据无法安全解码为文本，首版必须可显示字节长度，并提供只读十六进制/二进制预览。任意字节编辑方式待负责人确认；助手建议首版不提供逐字节内联编辑，允许用户明确选择“用文件/十六进制输入完整替换”，保存前显示字节级差异和覆盖提示，并使用 version CAS。

## ACL 首版范围（待确认）

ACL 编辑已后置。首版可选择完全不展示 ACL，或只读显示 ACL 帮助解释权限错误；助手推荐只读显示，且将读取权限不足和 ACL 内容不可见明确区分。

## 认证身份版本范围

- 首版支持连接级认证配置，这是访问受保护集群的基础连接能力。
- 按路径/路径前缀绑定不同身份、自动切换连接属于第二版；需使用隔离的客户端/session 并始终显示当前身份。
- ACL 编辑为后续能力，不因第二版身份绑定自动视为包含。

## 命令行入口（产品边界已确认，语法待设计）

- CLI 只表达 ZooKeeper 连接、节点、ACL、数据和巡检等应用操作；不运行任意系统 shell 命令。
- CLI 属于当前工作台，可使用当前连接与节点上下文，也应能显式指定目标连接和路径。
- CLI 提供命令自动补全；补全内容至少包括命令、子命令、参数和可安全枚举的路径子节点。权限不足或连接不可用时应清楚反馈。
- 用户可以保存单条常用命令，也可以保存由多条命令组成的脚本文件，并从应用界面一键执行。
- 脚本按文件中的行顺序逐行执行；提供执行全部和执行当前行两种操作。不得并行重排命令。
- 一条命令由换行符或分号 `;` 结束；解析器不得将引号内的分号误作结束符。
- 脚本遇到第一条命令失败时立即停止后续执行，并返回失败命令及错误。
- 执行前展示目标连接和脚本中的写操作摘要；写操作摘要至少包含操作类型及目标路径。
- 命令输入区提供基础语法高亮。
- 每条命令完成后返回该条命令的结果；失败时返回明确错误，不得伪装为成功或静默丢弃错误。
- 脚本中的每次查询分别保存本次执行结果，并以可折叠条目呈现；用户可选择展开查看具体结果。
- 每条结果至少关联脚本行号、命令文本、执行状态和结果/错误。结果是否跨应用重启持久保存，待确认。
- 查询结果仅在当前脚本运行或当前应用会话中保留；不得跨连接/认证身份持久共享。身份/连接切换后清除或隔离结果，避免权限上下文混淆。
- 命令和脚本复用 Rust 核心的连接管理、版本保护、错误处理和审计，不得绕过这些控制。
- UI 采用多连接工作台思路组织连接、对象树、数据编辑和命令操作区域；DataGrip 仅作为交互模式参考，不构成视觉复制要求。

### 待确认的脚本执行语义

- 是否支持变量、条件、循环和环境变量？（推荐首版只支持顺序命令与注释，不引入通用脚本语言。）
- 是否需要高亮错误行、显示逐行运行状态及结果？（推荐需要。）
- 是否提供脚本目录浏览/管理和内置文本编辑器？（已提出，能力边界待确认。）
- 脚本是否使用普通文本文件格式？（推荐可读文本格式，便于版本管理；凭据禁止写入脚本。）
