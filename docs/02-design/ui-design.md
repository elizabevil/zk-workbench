# ZK UI 界面设计说明

## 目的

本文件描述 UI 的信息架构、布局、关键交互和状态反馈。产品需求仍以 `01-product/prd.md` 为准，具体功能行为以相应 `03-specs/` 为准；本文件不重复抄写完整需求。

## 推荐的描述方式

采用 **Markdown 文字规格 + 低保真线框图 + 状态/交互表**：

- Markdown 记录页面目标、区域职责、操作、快捷键、反馈和设计决策，方便搜索、评审和变更追踪。
- Mermaid 可用于页面关系、导航流或简单状态图；不适合精确描述像素布局。
- 复杂页面用嵌入式 SVG/PNG 线框图，并以编号标注区域；图下用表格说明每个区域。图应放在本文件相邻的 `assets/` 中；若文档规范禁止该子目录，则使用 `02-design/` 内的固定命名图文件并在本文件引用。
- 不建议仅用长段 Markdown ASCII 艺术图描述最终布局，也不建议自创 UI DSL；两者难维护或难形成视觉共识。
- 进入视觉定稿后，可将 Figma 等设计稿作为链接证据；文档仍保留关键行为、状态和决策，不让外链成为唯一规范。

## 全局工作台结构（初稿）

```text
┌──────────────────────────────────────────────────────────────────┐
│ 顶部：应用菜单 / 连接切换 / 连接状态 / 常用操作                   │
├──────────────┬──────────────────────────┬────────────────────────┤
│ 连接与对象树 │ 主工作区：节点数据/编辑器 │ 检查器：Stat / ACL 等   │
│              │                          │                        │
├──────────────┴──────────────────────────┴────────────────────────┤
│ 底部工具区：ZooKeeper 命令 / 脚本 / 输出 / 操作时间线             │
```

这是信息区域草图，不是已批准布局。多栏是否可折叠、底部工具区是否为标签页、命令面板与节点编辑如何并列，需通过后续场景讨论确认。

## 区域职责（初稿）

| 区域 | 主要用途 | 关键状态/反馈 |
|---|---|---|
| 连接切换 | 选择、创建和管理 ZooKeeper 连接 | 连接中、已连接、断开、重连中、会话过期 |
| 对象树 | 展开子节点、路径定位、缓存内搜索 | 未加载、加载中、空节点、错误、可能过期 |
| 主工作区 | 查看原始数据、JSON/YAML 格式化视图和编辑内容 | 原始/格式视图、搜索/替换、未保存、冲突、保存成功/失败 |
| 检查器 | 查看 Stat、ACL 等节点元信息 | 加载中、无权限、读取失败、刷新时间 |
| 命令与脚本 | 输入命令、补全、逐行/单行执行及查看结果 | 当前目标连接、当前行、执行中、失败行、写操作摘要 |
| 操作时间线 | 查看本工具发起的变更记录 | 空状态、筛选结果、记录详情 |

## 认证身份提示（提案）

ZooKeeper ACL 按 znode 生效，认证身份附着在客户端连接上。若采用本地路径到认证配置的绑定，连接选择器、路径栏和命令面板应显示当前实际使用的认证配置；切换路径导致身份配置变化时应显式提示，不能在共享会话上静默叠加认证身份。此交互仍待负责人确认，见 `CHG-0002` 主题 4。

## 命令与脚本编辑区（初稿）

- 命令输入或脚本编辑区必须显式显示目标连接；切换连接时避免静默改变正在编辑脚本的执行目标。
- 每行是一个命令；支持执行当前行和按文件顺序执行全部行。
- 基础语法高亮只辅助识别命令、参数、字符串和注释，不改变命令含义。
- 自动补全列表从命令语法和当前连接上下文提供候选项；补全路径不得被误解为全局搜索。
- 执行前展示目标连接及写操作摘要；执行中显示当前行，执行后保留逐行结果。
- 每次查询的结果单独保存为一项并默认折叠；用户可展开查看。失败项显示明确错误，可展开查看错误详情。
- 脚本第一条失败命令立即停止后续执行，并保留逐行结果。
- 目录浏览和文本编辑器范围待定；当前只考虑应用管理的脚本目录，不承诺通用文件管理能力。

## 节点数据查看与编辑

- 查看面板提供原始内容和格式化视图；JSON/YAML 均提供高亮。格式化仅改变视图，不修改底层读取内容。
- 搜索/替换只作用于本地编辑草稿；显示未保存状态，保存前展示 diff 并进行 version 检查。
- 查看与编辑模式应明确区分，避免用户将缩进/格式化误认为已修改或已保存。
- ACL 管理不进入首版 UI；按路径绑定认证身份计划第二版实现。
- 搜索/替换应提供常规编辑器工作流：查找条、匹配数、上/下一个、替换当前项、替换全部、关闭与撤销；正则等选项由规格确定。
- 不可解码内容显示字节数和只读十六进制预览。若批准完整替换，使用独立的显式替换流程，展示字节差异、目标路径和 version 冲突状态，不伪装成普通文本编辑。

## 危险操作确认

- 所有删除操作均显示确认步骤；递归/批量删除必须明确标出根路径、范围及可获得的节点数量。
- 提供明确动作选项，例如删除当前空节点、删除当前节点及后代、删除父节点下指定子节点；避免一个模糊的“删除”按钮隐含递归行为。
- 执行过程显示进度；部分失败时区分已删除、失败和未执行对象。
- 执行确认需再次展示当前连接和认证身份。

## 后续逐步补充

1. 连接与启动场景：首次运行、无连接、连接失败、重连。
2. 节点浏览与编辑场景：路径定位、大节点、格式识别、保存冲突。
3. CLI/脚本场景：补全、单行执行、整文件执行、错误恢复。
4. ACL、巡检、审计场景。
5. 键盘导航、可访问性、窄窗口和高 DPI 行为。
