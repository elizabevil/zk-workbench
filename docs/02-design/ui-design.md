# ZK UI 界面设计说明

本文件描述信息架构、布局、交互与状态反馈。可验收行为以 `req/` 为准，本文件不重复需求正文；视觉细节（色彩、间距、图标）在实现阶段由设计令牌定义。

## 1. 主工作台布局

```text
┌───────────────────────────────────────────────────────────────────────────┐
│ ① 顶栏   [连接: prod-zk ▾]  [● 已连接  12ms]  [身份: digest:alice]  [设置]  │
├────────────────┬──────────────────────────────────────────┬───────────────┤
│ ② 连接与树      │ ③ 数据工作区（多标签）                     │ ④ 检查器       │
│ ┌────────────┐ │ ┌─────────────┬─────────────┬──────────┐ │ ┌───────────┐ │
│ │路径直达 ___│ │ │/app/config ✕│/app/a ● ✕   │ +        │ │ │ Stat       │ │
│ └────────────┘ │ ├─────────────┴─────────────┴──────────┤ │ │ ...        │ │
│ [搜索(本地)__]  │ │ [原始|格式化] [JSON ▾] [只读] [刷新]  │ │ └───────────┘ │
│ ▾ /            │ │ ┌──────────────────────────────────┐  │ │ ┌───────────┐ │
│   ▾ app        │ │ │ 编辑器 / 大节点预览               │  │ │ │ ACL(只读)  │ │
│     config     │ │ └──────────────────────────────────┘  │ │ │ ...        │ │
│     a          │ │ 未保存 ●   [保存] [放弃]  [显示 diff] │ │ └───────────┘ │
│   ▸ zookeeper  │ └──────────────────────────────────────┘ │               │
├────────────────┴──────────────────────────────────────────┴───────────────┤
│ ⑤ 命令区（默认折叠，可拖拽） [输入 zkCli 命令______] [执行][全部][历史 ▾]    │
│ ⑥ 结果/历史  [结果][历史]  逐条折叠，失败行高亮                             │
├───────────────────────────────────────────────────────────────────────────┤
│ ⑦ 状态栏  连接/generation | 数据新鲜度 | 日志: ~/Documents/zkui            │
└───────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 职责 | 可折叠 | 记忆 |
|---|---|---|---|
| ① 顶栏 | 连接切换、连接状态、当前身份、设置入口；应用菜单使用系统原生菜单栏 | 否 | — |
| ② 连接与树 | 路径直达、本地范围搜索、按需展开 | 是 | 宽度、展开状态 |
| ③ 数据工作区 | 多标签查看/编辑、diff、保存 | 否 | 标签集合、每连接最近 3 个 |
| ④ 检查器 | Stat 与 ACL 只读展示 | 是 | 宽度、折叠状态 |
| ⑤ 命令区 | zkCli 命令输入与执行 | 是（默认折叠） | 高度 |
| ⑥ 结果/历史 | 逐条结果、命令历史与重跑 | 与⑤联动 | 当前标签 |
| ⑦ 状态栏 | 连接、generation、新鲜度、日志路径 | 否 | — |

窗口最小建议尺寸 1024×640；窄窗口下检查器默认折叠，树与数据区按 30/70 分配。

## 2. 多标签模型

| 规则 | 内容 |
|---|---|
| 打开 | 双击树节点、路径直达、命令结果中的「在面板打开」 |
| 去重 | 同一连接下同一路径只保留一个标签，重复打开即激活 |
| 脏标记 | 未保存时标题前显示 `●`；关闭标签时提供「保存 / 放弃 / 取消」 |
| 连接隔离 | 标签集合按连接独立保存，切换连接不关闭标签 |
| 保留上限 | 仅保留最近 3 个连接的标签集合；超出时移除最久未激活连接的标签，若其中含未保存内容必须先提示 |
| 数量提示 | 单连接标签超过 20 个时提示可能增加内存占用 |

## 3. 检查器

- 右栏上下两段：`Stat` 与 `ACL`（只读）。
- Stat 展示 `cZxid/ctime/mZxid/mtime/pZxid/cversion/dataVersion/aclVersion/ephemeralOwner/dataLength/numChildren`，并显示本次读取时间。
- ACL 只读展示 scheme/id/permissions；权限不足时显示「不可见（权限不足）」，与「无 ACL 条目」明确区分。
- 修改 ACL 只通过命令区 `setAcl`，检查器不提供编辑入口。

## 4. 命令区与结果

- 默认折叠，展开后高度可拖拽并记忆；折叠时保留最后一条命令与状态摘要。
- 输入区提供 zkCli 语法高亮、补全与历史下拉；执行当前行与执行全部两个动作。
- 结果面板逐条折叠，展示行号、命令、状态与结果/错误；失败行高亮并可展开详情。
- 写操作执行前在结果区上方插入确认条：目标连接、身份、写操作摘要（`setAcl`、`addauth`、`deleteall` 等）。

## 5. 状态模型

| 对象 | 状态 | 呈现 |
|---|---|---|
| 树节点 | 未加载 / 加载中 / 空 / 错误 / 可能过期 | 图标与行内提示；过期节点置灰并加标记 |
| 数据标签 | 原始 / 格式化；未保存 / 已保存 / 冲突 / 保存失败 | 视图切换按钮、标题圆点、横幅 |
| 连接 | 创建中 / 连接中 / 已连接 / 断开重连中 / 会话过期 / 关闭 | 顶栏状态点与文案，状态栏保留 generation |
| 数据新鲜度 | 新鲜 / 可能过期 | 内容区顶部横幅，提供「刷新」 |

## 6. 关键流程

1. **定位与读取**：顶栏选连接 → 树按需展开或路径直达 → 双击打开标签 → 右栏并行加载 Stat 与 ACL。
2. **编辑与保存**：切到编辑 → 修改（标题出现圆点）→ 「显示 diff」内联高亮 → 保存（版本 CAS）→ 冲突时横幅提示「已被其他客户端修改」，提供「重新读取 / 以新版本覆盖（二次确认）」。
3. **删除**：右键删除 → 非空节点确认按钮置灰 → 勾选「删除全部 N 个后代」→ 预览前 100 条与总数 → 确认（展示连接与身份）→ 进度与分项结果 → 可「仅重试失败子树」。

## 7. 快捷键

| 快捷键 | 动作 |
|---|---|
| `Ctrl/Cmd+Enter` | 执行当前命令 |
| `Ctrl/Cmd+Shift+Enter` | 执行全部脚本 |
| `Ctrl/Cmd+Space` | 触发补全 |
| `F5` | 刷新当前子树 |
| `Ctrl/Cmd+K` | 清空结果 |
| `Ctrl/Cmd+S` | 保存当前标签 |
| `Ctrl/Cmd+W` | 关闭当前标签 |
| `Ctrl/Cmd+Tab` | 切换标签 |

## 8. 组件映射（Naive UI）

`NTree` 树、`NTabs` 数据标签、`NSplit` 面板分割、`NModal` 确认与冲突、`NDrawer` 错误详情、`NNotification` 轻提示、`NMenu` 应用菜单、`NInput` 搜索与命令输入；编辑器为 CodeMirror 6 嵌入（`DEC-003`）。

## 9. 空状态与错误

- 无连接：居中引导「新建连接」，附本地保存说明。
- 无标签：提示「从左侧树选择节点，或输入路径直达」。
- 权限不足：内联提示 + 身份标签，不弹出模态框。
- 连接断开：顶栏状态变化 + 内容区横幅，不阻塞已加载数据查看。

## 10. 候选方案与权衡（Alternatives & Trade-offs）

**单标签数据区**：实现简单，但无法并排对比两个节点，且切换会丢失滚动位置；被拒绝，改为多标签。

**检查器并入数据标签**：可省右侧空间，但 Stat 与 ACL 需要在每个标签内重复渲染，且查看元信息会挤占编辑区；被拒绝，改为独立可折叠右栏。

**命令区常驻**：随时可用，但压缩主工作区高度，与「以树和编辑为主」的使用分布不符；被拒绝，改为默认折叠可拖拽。

## 11. 非目标（Non-Goals）

1. 不定稿色彩、字号、间距与图标风格（实现阶段定义设计令牌）。
2. 不设计移动端或窄屏布局。
3. 不提供 ACL 编辑界面（仅命令行 `setAcl`）。
4. 不设计导入导出、巡检面板与时间线的细节（对应阶段再展开）。
5. 不定义国际化文案。

## 12. 国际化与配置

- 语言：中文、英文；文案来自语言包，Rust 只返回错误码与参数，前端按 `message_key` 渲染；原生菜单文案随语言刷新。
- 主题：`theme.json` 提供颜色、圆角、间距等令牌，经 CSS 变量与 Naive UI `themeOverrides` 生效。
- 配置：内嵌默认值 + 用户目录覆盖；配置只调整呈现与阈值，不得改变行为语义。
- 不提供退出快捷键，退出通过原生菜单。
