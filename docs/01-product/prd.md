# ZK UI 产品需求

## 产品定位

ZK UI 是面向开发和运维人员的 ZooKeeper 桌面管理工作台。产品重点解决状态一致性、写操作安全和工作流连续性，而非单纯增加 CRUD 数量。

## 产品边界

- 首版面向 Windows、macOS、Linux 桌面端。
- 规划节点 CRUD、ACL、多集群、SSH Tunnel、四字命令巡检、本地审计、数据格式化与 diff。
- 首版不做移动端或 Web 共享服务。
- 跨平台目标是共享 Rust 核心和一致的行为语义，不要求像素级一致。
- 首版和当前产品范围聚焦 ZooKeeper；借鉴同类产品交互，不把 etcd 等后端纳入当前承诺范围。
- 首版及当前产品范围聚焦 ZooKeeper；借鉴其他中间件工具的工作区和交互模式，不把 etcd 等后端纳入当前承诺范围。新增中间件需另行完成产品定位决策。

## 产品优先级

1. **首版：单节点的可靠节点操作工作台。** 优先保证围绕一个目标 znode 的定位、读取、数据/ACL 查看与操作、版本冲突保护、结果反馈及重连后状态可信。这里的“单节点”描述首版核心操作粒度，不预设产品只能连接一个集群。
2. **其次：节点数据维护与迁移工具。** 在可靠读写基础上增加多格式编辑、脚本化测试流程、数据导入导出和迁移能力。
3. **再次：集群运行巡检台。** 增加多集群运行指标、四字命令巡检、阈值判断等能力。

后续能力不得挤占首版核心闭环的验证和交付；若跨阶段能力是首版闭环的必要依赖，应明确说明依赖理由。

## 用户需求

### PRD-001 连接和工作区

用户可以管理多个 ZooKeeper 集群连接，并在本地保存各连接的浏览路径、树展开状态、关键节点标记和数据格式偏好。切换或重启应用后可以恢复工作现场。工作区状态不写入 ZooKeeper。

### PRD-002 浏览与定位节点

用户可以按需浏览节点树，也可以通过绝对路径直达节点。应用不得为普通浏览而预先加载整棵树。

### PRD-003 查看和编辑节点

用户可以查看节点数据与 Stat，并对持久、临时、顺序等 ZooKeeper 节点类型执行创建、读取、修改和删除。首版支持递归操作。删除属于危险操作，必须由用户明确确认；确认需说明目标路径和影响范围。ACL 权限管理后置；首版是否只读显示 ACL 待确认。数据查看支持格式化视图，格式化只改变展示，不修改存储内容。

### PRD-004 安全写入

写操作默认使用 ZooKeeper version 检查。发生版本冲突时不得静默覆盖，应提示节点已被其他客户端修改并允许重新读取比较。

### PRD-005 连接状态与实时性

应用应清楚呈现连接、断开、重连和数据可能过期状态。会话重建后刷新相关展开子树，不得把旧缓存呈现为已确认的新鲜数据。

### PRD-006 集群巡检

用户可以按集群、实例、指标查看四字命令结果及阈值状态。巡检不可用不得误报为 ZooKeeper 连接故障。

### PRD-007 本地操作追溯

应用记录自身发起的节点和 ACL 变更，包括时间、连接、路径、操作类型、版本变化和结果；提供节点历史与全局时间线。该能力不宣称是合规审计，也不覆盖其他客户端操作。

### PRD-008 大节点与数据交换

大节点默认显示长度和预览，用户按需加载完整内容。用户可以导入导出连接配置及约定支持的数据；不得意外导出明文凭据。

### PRD-011 多格式数据查看与编辑

用户可以查看 ZooKeeper 节点原始数据，并对 JSON、YAML 提供格式化和语法高亮。编辑器支持参考 DataGrip 等常规数据库/代码编辑器的搜索与替换能力。查看模式中的格式化只改变展示，不修改实际存储数据；只有用户明确保存后才写入 ZooKeeper。不可解码原始字节的编辑/替换策略待确认。

### PRD-012 ZooKeeper 应用命令行

应用提供面向 ZooKeeper 操作的命令行入口，作为 UI 的一部分。CLI 支持命令自动补全，并可保存命令及脚本文件供后续执行；不提供任意操作系统 shell。

### PRD-013 脚本流程执行

用户可以保存 ZooKeeper 命令脚本，并按行、顺序执行；也可以逐行执行当前脚本。执行前展示目标连接和写操作摘要。命令输入区域提供基础语法高亮。脚本文件管理和编辑体验待进一步确定。

### PRD-014 多连接工作台

用户可以在同一工作台管理多个 ZooKeeper 连接，并在连接、节点树、数据编辑器和命令入口之间切换。交互组织参考 DataGrip 等多数据库客户端；不要求复刻其视觉设计。

### PRD-015 按路径绑定认证身份（第二版）

用户可以为本地工作区中的路径或路径前缀绑定认证身份配置，以便针对不同权限区域选择对应 ZooKeeper 连接身份。此能力计划在第二版交付；首版只支持连接级认证配置，不提供路径级身份自动切换。

## 工程约束

### PRD-009 技术栈

当前方向为 Rust + Tauri 2 + Vue 3。连接池、ZooKeeper 会话、Watcher、巡检、审计和凭据处理由 Rust 核心承载；前端不持有 ZooKeeper 协议知识。

### PRD-010 安全边界

凭据不得以明文持久化。Tauri 命令权限按最小能力配置，不能依赖前端条件分支作为安全边界。

## 暂不纳入

移动端、Web 共享服务、多用户远程工作区、集中式合规审计、未经确认的离线写入和自动同步。
